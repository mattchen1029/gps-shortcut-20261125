One line, at most 200 characters: the GPS's own excuse for sending the driver down the wrong road. Entry for make.fun's "The GPS Swears It Was a Shortcut" bounty.

The program writes a single excuse line to `/output/entry.txt`:

> The map called it a shortcut. The map also called the lake a parking lot. I have never seen a lake, and I stand by the map.

## Run it

```sh
python3 main.py
```
